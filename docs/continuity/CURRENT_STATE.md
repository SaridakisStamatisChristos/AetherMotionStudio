## Canon — durable product constraints
1. Offline-first procedural production, validated declarative scenes rather than arbitrary LLM-generated executable code. Core does not require a remote provider. Remotion 4.0.546, Three.js 0.180.0, React 19.2.0 pinned direct dependencies; Node 22 and Python 3.11 are the supported acceptance baseline. Kokoro ONNX local voice; model checksums in models-lock.json. First setup needs network; subsequent runs can be offline with cached dependencies/models/browser. No unauthorized licensing or redistribution claims.
2. Both renderers first-class: CPU Canvas portable and GPU-independent, Three.js native WebGL. Share graph, semantic geometry, camera/animation, measured timeline, caption/voice contracts. Different lighting/shading allowed; no silent substitutions. Maintain legacy v1 (12s), v2 multi-shot fixed/automatic frame budgets up to 300s, 1080x1920 30fps default. Frame-addressed deterministic output; no wall-clock/network from draw functions. Compatibility changes additive, versioned and tested.
3. Preserve 250 object/50 motion/30 effect legacy presets, all old IDs, original/polished fidelity, identity and continuity invariants, authored examples. Foundry extends via opt-in geometry/material/LOD/packs, pinned revisions/digests, explicit generated-asset promotion, import quarantine/validation; no untrusted code execution. Do not silently downsample or modify old recipes. AF09 frozen protocol and original evidence remain immutable; new benchmarks use distinct versioned protocols.
4. Measured speech is authoritative; estimated word timings are not forced alignment. Same source preparation for matched renders; exact frame budget and no clipping, no fake fallback. Camera quality repair opt-in, bounded, protects authored scene content. Verify real H.264/AAC frame count/duration/full decode and user review; pixel differences are diagnostic only.
5. Local Studio loopback, safe validated paths, revision conflict checks, immutable render snapshots, bounded logs and explicit errors. No auth/SaaS/cloud project unless requested. Keep models, MP4s, node_modules, local machine configs/secrets out of repo. No unrequested architecture changes or global installs.
6. Source and approved decisions authoritative. This summary cannot discard binding facts; consult the source-specific contract when the task touches it. Keep state and handoff synchronized. No new native render runs on GitHub or release without authorization.
