# v0.6 persistent identity and continuity (candidate)
Identity library v1 holds up to 64 stable named definitions (character, prop, environment) with recipeVersion=1. Objects bind existing asset recipe, immutable appearance and default pose, up to eight named color variants. Dimensions cannot change via variant. Legacy retro-robot/chest/core preserve original geometry and colors. Environments bind existing palette and optional world layer preset. Catalog retains 250 objects, 50 motions, 30 effects.
Director request may embed identityLibrary and cast (1–8 IDs). Prompt receives selected IDs, names, variant IDs and rig capabilities, not full appearance geometry. Identity IR uses identity instead of asset, optional variant and hold. Compiler resolves canonical graph bindings and validates again at project/renderer boundaries; conflicting params, unknown variants, duplicate instances and untracked attachments rejected. Legacy v2 still validates without library. Rehydrate from exported JSON, not account memory. Ledger, neutral geometry fingerprints and five frame samples per shot accompany output. Neutral fingerprints deliberately exclude pose; procedural continuity, not face recognition.
Shared arm/hand pivots and exact hand anchors for retro and catalog human/robot families; catalog arms use rotated shoulder-to-hand vector and optional grip geometry. Catalog robot blink, human/robot/animal walking where supported, head controls only for retro. Human/robot/animal colors and proportions support reusable appearances; variants change colors only. Hands carry props using bounded offsets and short continuous pickup blend; detach freezes world origin. No generalized IK, finger skeleton, collision physics, facial rig or new anatomical meshes. Animals lack hand anchors. Existing recipes retained; no extra geometry without grip. Rig metadata describes implemented channels and procedural hierarchy, not a fully articulated skeleton.
Continuity ledger compares exact expected move, variant, pickup and release events to author intent. Held prop cannot vanish, change holder or hand without release or overlap two props in one hand. Prop and holder must be visible; offscreen holdings rejected conservatively. Release uses attachment end<1; end=1 carries hold across cut. Reentry warning; positions shot-local, no world path reconstruction. Narration semantic consistency and automated accessory authoring remain later work.
CLI: npm run director -- --request examples/continuity-cpu-polished.request.json --render. Reuse library: npm run director -- --topic "Another story" --seconds 30 --library examples/identity-library.json --cast orion,repair-tool,launch-lab,city-station. Opt-in neutral geometry audit: npm run audit-assets --silent > asset-audit.json. All 250 objects audited for finite deterministic neutral geometry, box counts, bounds and capabilities; not native visual/pose coverage. --story delivery selects finite five-beat offline story with one hand-rig character, one prop, two environments, 45–90 seconds. Generic offline cast mode reuses identities without inventing events; model-assisted mode may generate different valid story. Existing v0.5 modes unchanged without library.
