# AF08 portable packs and Studio manager

Use `npm run foundry:packs -- list`, `search '{"kind":"hero","category":"characters"}'`, `export-pack retro-lab retro.pack.json`, `verify-pack retro.pack.json`, `import retro.pack.json`, `inspect hero retro-robot`, `render-preview generated survey-beacon beacon.bmp`, and `compile portable-project.json project.json`. Default local store studio-data/packs; AETHER_PACK_DIR may override the CLI store. Studio runs on existing loopback server. The Foundry section searches metadata, inspects an exact revision, chooses LOD/view/light, exports or imports a JSON pack, and inserts a pinned asset into an explicitly compatible premium graph. No silent legacy migration. Position edits use existing shot inspector; advanced JSON permits existing supported track parameters. Imported revisions remain immutable. Pack v1 carries exact manifest digest, dependency digests, license and attribution; built-in heroes require matching installed compiler and content fingerprints, generated recipes are compact embedded dependencies. No external mesh/texture redistribution, archives, network or executable assets. Existing legacy entries remain browsable separately. Material/dimension filters compile only candidates on demand; legacy geometry has no premium dependency. Six camera previews are on demand, not a continuous turntable movie; lighting views are not arbitrary material edits. Native Three remains unverified. Browser UI interactions require further manual review; HTTP persistence is tested. CLI concurrent writers across processes are not coordinated; Studio serializes its own pack writes.

Acceptance: `node scripts/foundry-packs.mjs acceptance` creates two exported packs, portable authored story, reloads exact dependencies offline, writes matched CPU/Three scene files and inspection/negative-case evidence. The single default film is AF08 CPU polished. Previous generated AF05/AF07 fixtures remain in manual full. No aesthetic approval or backend parity claim.
