# AF07 constrained generator

Run `node scripts/foundry-generate.mjs` offline to evaluate the frozen semantic requests, create both matched scene fixtures and write trace/evaluation evidence. Render only `npm run render -- examples/foundry-af07-cpu-polished.json` during development. The new Director option `foundryRequests` is an explicit opt-in to the 30-second laboratory story lane. The default Director and old projects are unchanged. No model-generated code, network access in renderers, or required external provider. Supported missing families are survey beacon, ceramic insulator and specimen canister. Unknown detailed geometry or articulation is unsupported. Exact known catalog names and declared aliases return reuse, not approximate lookalikes. Optional provider supplies only the supported semantic family, with at most two repairs; token counts are unavailable offline.

Recipe v1 supports bounded primitives, lathe, convex extrusion, sweep, groups, transforms/instances, fixed material presets, explicit ground/top anchors and root-only rig. All node references, depth, expansion, topology, finite parameters and aggregate resource limits are validated. Fixed LOD0; no new articulations or textures from provider. Generated references store compact recipe, compiler, identity, revision, geometry/material fingerprint, digest and original procedural provenance; no imported file masquerade. Inspection records CPU structural checks and six rendered still hashes with flags. Registry staging verifies evidence and deduplicates fingerprints; promotion requires explicit reviewer declaration matching revision and evidence. In-memory registry; portable persistent packs and manager deferred to AF08. Human declaration is not identity authentication. Native Three and artistic quality remain unverified. Evaluation counts categories separately; no placeholders or fabricated token counts.
