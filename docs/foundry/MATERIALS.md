# AF-02 premium surface contract

Optional shot materialProfile v1 requires geometryProfile foundry-af01. An assignment selects a known asset instance ID and preset, with bounded scalar overrides and optional texture descriptor. Original emissive components are preserved unless includeEmissive is true. Omission preserves AF-01 and all legacy renderer code paths. Materials: painted-metal, brushed-steel, anodized-aluminum, copper, gold, polished-plastic, matte-plastic, glass, acrylic, rubber, leather, fabric, wood, ceramic, concrete, stone, paper, emissive-display.

Texture maps are generated offline from periodic UV-space patterns and seed, with 256/512/1024/2048 resolution, bounded scale, strength and optional normal/occlusion maps. Base is sRGB; other maps are linear. SHA-256 map and texture digests, bounded 96 MiB raw map budget per shot/cache, no remote files. CPU bilinear sampling uses perspective-correct UVs and linear-light approximate diffuse/specular, metallic tint, roughness-dependent highlights, clearcoat approximation and emissive contribution. CPU opacity is a nearest translucent layer, not arbitrary multilayer transparency or refraction. Normal maps and environment reflection are not supported on CPU; transmission is explicitly rejected for CPU. Three.js MeshPhysicalMaterial uses native maps, filtering/mips, physical material parameters, alpha mode and optional transmission, plus original procedurally generated studio environment with PMREM. Native Three.js verification is deferred, not certified. GPU memory differs from raw map budget (mips/driver allocations). Texture cache is bounded; native textures/materials are disposed on profile changes and backend disposal. No new external dependencies.

Fixture: six 5-second studies (steel, wood, fabric, plastic, glass-like acrylic, emissive), each samples three deterministic key directions in one continuous sweep. Existing identities and mesh digests unchanged; camera rig closer than AF-01. Render only AF-02 CPU by default; matched Three.js plus all existing fixtures in manual full gate. Benchmark measures raw texture generation and CPU raster times, not full video speed. Subjective appearance and native Three.js remain separate gates.
