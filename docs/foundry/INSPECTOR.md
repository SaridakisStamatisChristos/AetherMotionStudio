# AF06 — unified asset inspection and human review

`npm run foundry:inspect -- batch` produces a bounded offline evidence set in out/foundry-af06-inspection. No external service, browser or model is required. The batch inspects 32 hero recipes × 4 LODs, 6 AF03 × 4 LODs, 4 AF01 fixed representations, 6 AF02 material-study variants and five AF05 imported format fixtures. Total 47 revision-specific records and 167 representations (2004 primary still views). Every original 250-object box emitter is covered structurally at neutral and two extreme poses, with its real emitter bounds, color, rig and content digest, without pretending the legacy box emitter has canonical mesh LODs. Small 96 px inspection tiles keep CI bounded; no turntable batch or extra video. Actual single polished film is separately rendered by production CI.

`npm run foundry:inspect -- asset retro-robot --turntable` generates a 256 px on-demand four-level sheet, 12 angular turntable frames (offline viewer scrubber), extreme pose sheet and RGBA + composited thumbnails per LOD. `npm run foundry:inspect -- bundle /path/to/staged.bundle.json` inspects an eligible digest-pinned import at its actual LOD0. Use FOUNDRY_INSPECTION_OUT to set an output directory. Do not put untrusted files in a writable directory shared with other processes.

Contact sheets: columns front, rear, left, right, top, three-quarter; rows alternate neutral and cinematic for LOD0, LOD1, etc. All views of an asset use common union bounds and padding. Alpha thumbnails are actual transparent raster data. Frame order verification uses five sampled yaw/pose frames rerendered out of order; held-out side lighting and independent camera positions are not the sheet views. Screen-space multi-asset probe measures overlap, front-preserved pixels and separation; it is not a physics collision solver. Reports include per-view raster time, warm command generation time, process peak RSS (cumulative), counts, groups, texture hashes/dimensions, topology audit, finite attributes, bounds, anchors, rig integrity, occupancy, clipping, abnormal alpha, excessive highlights and large sequential changes. Expected edge-on empty planar views are recorded, not silently replaced. Machine warning thresholds are heuristics; no score is inferred from them. Geometry defects block; visual flags are retained for review. No native Three inspection or RTX comparison. AF01/03 neutral uses actual fixed-light geometry raster; cinematic and held-out side lighting use explicit CPU material relighting, recorded per view, not silently substituted. AF02/04/05 use material raster. Isolated previews do not include production effects, shadows or typography.

Human review: open index.html, inspect record JSON and sheet, then create a separate human-input.json with reviewer, decision (approved/rejected/refinement-requested), scores (integer 1 poor through 5 excellent; motionInteraction null only for static assets), notes, outstandingFixes and knownLimitations arrays. All eight dimensions required: recognizability, proportion, silhouette, materialCoherence, detailHierarchy, motionInteraction, cameraFraming, cinematicSuitability. Approval cannot have unresolved fixes; rejection/refinement needs actionable fixes. `npm run foundry:inspect -- review path/to/record.json path/to/human-input.json` validates actual sheet SHA256, records reviewer as human-declared and appends to reviews/foundry/reviews.jsonl (override FOUNDRY_REVIEW_LEDGER). This is a local declarative ledger, not authenticated identity or signed audit. Review validity is scoped by ID, profile, revision and content fingerprint derived from actual mesh, material, texture, transforms, anchors, rig and sampled poses. Changes to one identity invalidate that identity's earlier review without invalidating unrelated assets. No review is generated automatically. Store ledger separately from generated out/ directory. Do not commit human review without explicit authorization.

CI gate: 250 structural records, all 32 premium manifests with all 4 LOD sheets, earlier Foundry and import records, malformed fixtures and actual reorder checks, one native CPU production scene. Native Three inspection stays deferred until explicit matched final gate.
