# AF-03 multi-LOD contract

Opt-in geometryProfile foundry-af03 + lodPolicy v1. Six existing identities: retro-robot, smartphone, temple, atom-model, treasure-chest, energy-core. No new catalog IDs. Four parametric levels (0 hero, 1 cinematic, 2 efficient, 3 preview); existing emitters are authoritative for component positions, pivot, articulation, material semantics and named rig anchors. Bundle revision 2.0.0 describes the same canonical identity, not four assets. Hero geometry increases parametric resolution; preview boxes have exactly 12 triangles and original UV orientation. Low-detail sphere/cylinder preserve cardinal extents; fixed cornice stays identical. Some multi-component assets exceed the aspirational LOD3 300 triangles because semantic parts remain; no component removal or arbitrary mesh simplifier.

lodPolicy: {version:1, quality:'hero'|'cinematic'|'efficient'|'preview', selection:'auto'|'explicit', overrides:[{asset:'instance-id',level:0..3}], budget:{maxTriangles,maxDrawCalls,maxGeometryBytes,maxTextureBytes}}. Explicit selection requires every asset. Automatic chooses level by maximum projected bounding-box size over nine evenly spaced samples plus authored camera/asset keyframes, action boundaries and assembly boundaries: >=480px LOD0, >=220 LOD1, >=80 LOD2, else LOD3; quality caps detail (hero allows 0, cinematic 1, efficient 2, preview 3). Explicit override wins. All frames use the same selected level, even when sampled out of order. Cache keyed by shot object and serialized contents; mutations invalidate. Budget exceedance fails with an explicit cheaper alternative, never silently downgrades. Sampled peak is not a continuous bound; each evaluated frame also checks actual mesh command resource usage before render. Environment uses preview primitives in AF03. Geometry bytes count unique typed buffers; texture estimates count distinct UV variants of raw maps, not mip/driver memory. Draw calls are command estimates, not measured WebGL renderer stats. Cache has at most 20 primitive-level entries.

CI publishes a six-identity four-level benchmark: actual triangle counts, estimated draw calls, unique geometry and texture bytes, cold geometry generation, cache hits/misses, matched raster times, silhouette IoU at three views/distances, Node process memory and max RSS. Native CLI publishes lod-report.json with selected levels, reasons and sampled peaks. Native film render timing and decoded output dimensions are separate artifacts. No imported mesh simplification or RTX 4060 measurement. Three fixture retained for final native gate. Legacy and AF01/02 unaffected. Tests compare component transforms and semantic attributes at an articulated pose, primitive topology/bounds, independent alpha-mask IoU, deterministic out-of-order selection, rejection of malformed and over-budget requests.
