# AF05 bounded local import
Run `node scripts/foundry-import.mjs ROOT RELATIVE_FILE PROVENANCE_JSON STAGING_DIRECTORY [Y|Z] [metersPerUnit] [targetHeight]`. Source root is a local staging directory controlled by the operator; safe relative names only, no remote URLs, percent encoding, absolute paths, dot segments, symlinks, archive extraction or executables. File count 32, total source bytes 16 MiB, source JSON 4 MiB, canonical serialized bundle 12 MiB, 100k aggregate vertices/triangles, 64 parts, 1M unique texture pixels. Local root should not be concurrently modified by an adversary; path checks do not constitute an OS sandbox. Quarantine metadata is emitted without parsing restricted sources. Eligibility based on declared license allowlist plus commercial/redistribution flags, not legal clearance. Preserve creator, source, exact version, license text/reference, attribution, modification and file hashes. Staged filename uses digest, no overwrite. Never fetch external sources.

Supported static subset: GLB/glTF 2.0, local binary buffers, float POSITION/NORMAL/TEXCOORD_0, integer indices, triangle primitives, static node TRS or affine matrices and nested transforms, base-color/roughness/metallic/emissive factors and local or embedded opaque PNG base map; unsupported extensions, compressed data, morphs, animation, skins, alpha, sparse accessors and double-sided material requests rejected. OBJ triangles or strictly convex planar quads, v/vt/vn, negative indices, local MTL Kd/Ns/map_Kd PNG; Ka/Ks and illum are parsed but not physically reproduced. OBJ axis Y/Z explicitly selected. SVG restricted to double-quoted rect and strictly convex polygon with solid hex fill and viewBox; extruded, never injected into markup. PNG non-interlaced 8-bit RGB/RGBA opaque only, CRC checked, bounded inflate, supports rectangular textures and planar props. No arbitrary SVG paths, text, filters, external refs or transparent decals. Blender optional conversion not implemented; no claims of unsupported functionality.

Import normalizes to centered X/Z, ground Y=0, target height and records source axis, meters/unit and transform. Canonical content digest verified before render. Use shot geometryProfile foundry-af05, asset imported-mesh with importBundle containing staged JSON, root transforms only, fixed imported LOD0. Mix with hero assets. CPU interpolates RGB texture in linear light; native Three adapter uploads bounded DataTexture, disposes per-profile materials and prunes unused geometry for imported shots; native WebGL verification deferred. CPU has no physically exact reflection or full imported PBR support. Imported assets are static and unrigged; no fake LOD generation. To reproduce fixture, run node scripts/foundry-import-corpus.mjs then npm run render -- examples/foundry-af05-cpu-polished.json. Corpus generates original GLB, glTF, OBJ/MTL, SVG and PNG fixtures, paired scenes and adversarial report; no external dependencies. Native matched pair retained as deterministic source generator.
