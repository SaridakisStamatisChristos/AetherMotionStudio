# AF-04 curated hero collection

Opt-in foundry-af04 pins hero-1.0.0 recipes and component materials. It does not modify the original 250-object catalog or AF01–03. Existing IDs reused for 28 targets; four new, premium-only canonical identities: mechanical-watch, laboratory-module, space-telescope, shipping-container (not equivalent to smartwatch, factory, ground telescope or package). Modern house uses townhouse; brutalist tower uses skyscraper; classic camera uses dslr-camera; dashboard kiosk uses kpi-dashboard; utility truck uses pickup-truck. Five thematic packs in the registry; original procedural provenance and project license policy. Pack entries are metadata only, not AF08 portable exports.

32 authored component recipes with stable semantic part names, explicit material roles, pivots and named anchors. Four parametric levels preserve component layout while reducing primitive tessellation (fixed extrusions/box pieces unchanged). No arbitrary mesh decimation or true vehicle dynamics; moving characters use original hand-anchor transforms, robot head/arm/leg channels and laptop/robot-arm open channel; other assets have root animation. Custom dimensions, identity-library pins, scene attachment/assembly, motion presets and material overrides fail closed on AF04, until a compatible versioned integration is implemented. Existing legacy projects unchanged. Some models use simple tapered solids, stylized approximations rather than physically exact models. Textures deliberately subdued. CPU material approximations from AF02 still apply. No independent artistic certification.

Run node scripts/foundry-hero-inspect.mjs after npm test. Generates 32 PNG sheets (front, side, rear, top, three-quarter, articulated pose or LOD2), 32 JSON review records, manifest and offline HTML index. Actual raster frames, not placeholders; checks reject blank or clipped views; records contain resource usage, component digests, anchors, bounds, elapsed raster times and SHA256. Human approval explicitly false; automated evidence cannot establish beauty. AF04 narrative fixture The Night Shift: recurring explorer in retro laboratory, terminal, atom, microscope, robotic arm, dashboard and laboratory module. Six five-second shots, 900 frames, authored movement, matched Three and CPU scene. Default CI renders CPU only; native Three remains deferred.
