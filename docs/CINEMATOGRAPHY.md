# v0.4.3 Cinematography (candidate)

Predecessor: 9339ed77b43c257d5405211457dcb7eb2ed2d79d, scoped CI 45352913631 passed. This increment is not a claim of accepted native output until the new scoped CI and MP4 are verified.

- Optional cameraRig: preset, subject asset ID, framing, padding, strength, targetOffset. Fifteen named camera techniques, eased sampling and explicit camera track precedence. Subject-aware geometry bounds use emitted boxes; camera correction and zoom are bounded heuristics, not physical collision avoidance. Rack focus approximates changing screen-space focus; no true optical focus plane. Near-plane CPU faces are rejected, not polygon-clipped.
- Optional actions per asset: ordered windows, speed, phase, weight, blend and once/loop/relative modes. Explicit tracks win; later actions blend into earlier results. Root actions work on all objects; new articulated actions initially supported on retro-robot only. Legacy motions unchanged. Grip is stylized. Props attach to a shared exact hand anchor with bounded offset; after end the world position is frozen, independent of frame history. Parent graph cycles rejected.
- Optional solar-panel assembly: stable emitter order, reveal, assemble/disassemble, explode/implode, highlight. No arbitrary mesh morphing. Other component recipes are not advertised as supported.
- Shared screen overlays: title, lower third, label, callout, arrow, counter, bar/line/pie, timeline, equation and network. Data values, units, axis labels, bounded counts and nonoverlapping slots. Charts are authored illustrative values, not measured real-world datasets. Text uses Canvas max-width; visual readability requires review.
- Three layered world environment presets; actual depth parallax in both renderers. Cut, fade, wipe, slide and match-style dimming are zero-overlap transitions. Slide is a sliding matte, not compositing adjacent shots. Match is a restrained dim, not content-aware matching.
- 45-second six-shot sunlight-to-smart-city story, same guide, attachment, assembly, data and narrator. Matched CPU/Three JSON. Scoped push renders CPU only, all prior fixtures retained. Full pair comparator checks v0.4.2 and v0.4.3 independently. Review frames include shot start/middle/end, exact frame and audio checks.

Commands: npm test; npm run validate -- examples/cinematography-cpu-polished.json; npm run render -- examples/cinematography-cpu-polished.json. Native Three.js acceptance and aesthetic review remain separate. Full suite is deferred by explicit user instruction. No changes to historical artifacts or baseline release.
